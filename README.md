# 🧽 Оспанджоббить: LLM Automation Pipeline

Асинхронный конвейер обработки изображений, использующий локальные LLM (LLaVA, Qwen), архитектуру MCP (Model Context Protocol) и Cloudflare Workers AI (Flux.2 Klein).

## 📌 О проекте
Пользователь загружает фотографию и выбирает персонажа из выпадающего списка. Система автоматически анализирует изображение, определяет эмоциональный окрас сцены, генерирует контекстную реплику от лица выбранного персонажа и перерисовывает сцену в стиле мультсериала "Губка Боб".

## 🏗 Архитектура
Проект построен по паттерну **MCP Host-Client-Server**:
1. **Frontend (`index.html`)**: Интерфейс для загрузки фото и выбора персонажа.
2. **Host / Web Server (`web-server.js`)**: 
   - Принимает HTTP-запросы (Express).
   - Использует **LLaVA** для Vision-анализа (получение описания сцены).
   - Использует **Qwen 2.5** для классификации эмоций и генерации текста.
   - Выступает как **MCP-Клиент**.
3. **MCP Server (`mcp-server.js`)**: 
   - Изолированный процесс, общающийся с Хостом по протоколу JSON-RPC через Stdio-транспорт.
   - Взаимодействует с Cloudflare Workers AI (Image-to-Image).
   - Не имеет доступа к контексту браузера (строгая изоляция процессов).

## 🛡 Engineering Highlights (Инженерные фичи)
- **Reliability (Надежность):** Реализован механизм Exponential Backoff (задержки 1s, 2s, 4s) и таймауты запросов (`AbortSignal.timeout(20s)`) для предотвращения зависаний при сбоях Cloudflare API.
- **Fallback Strategy:** Если фильтр безопасности (NSFW) Cloudflare блокирует запрос (HTTP 400), система автоматически подставляет оригинальное изображение персонажа, не прерывая работу пайплайна.
- **Observability (Наблюдаемость):** Сквозное логирование с генерацией `traceId` (UUID) для отслеживания каждого этапа обработки конкретного запроса.
- **Context Management:** В `web-server.js` реализованы массивы истории (`historyQwen` и др.) для передачи последних 5 сообщений (Few-Shot Context) в LLM, чтобы персонаж сохранял нить диалога.
- **Prompt Registry:** Все системные и пользовательские промпты вынесены в отдельный файл `prompts.js` (принцип Separation of Concerns).
- **Storage Management:** Разделение статических ассетов (`public`) и динамически генерируемого контента (`generated`). Сгенерированные картинки исключены из Git.

## 🧪 Evals (Тестирование LLM)
В папке `evals/` находится скрипт `test-mood.js` для проверки точности классификации эмоций моделью Qwen (3B). 
*В ходе тестирования выявлено, что модель путает агрессию с грустью. Внедрение Few-Shot Prompting (примеров прямо в системном промпте) позволило повысить точность классификации на тестовом наборе данных.*

## 🛠 Стек технологий
- **Node.js / Express** — бэкенд и маршрутизация.
- **@modelcontextprotocol/sdk** — реализация MCP-клиента и сервера.
- **Ollama (LLaVA, Qwen 2.5)** — локальные нейросети (Vision и Text).
- **Cloudflare Workers AI** — облачная генерация изображений (Flux.2 Klein).
- **Zod** — валидация аргументов MCP-инструментов.
- **Multer** — загрузка файлов.

## 🚀 Как запустить локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/shrevvd/llm_sponge_bob_project.git
   cd llm_sponge_bob_project
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Создайте файл `.env` в корне проекта на основе `.env.example` и добавьте ваши ключи Cloudflare:
   ```env
   CLOUDFLARE_API_TOKEN=ваш_токен
   CLOUDFLARE_ACCOUNT_ID=ваш_id
   ```

4. Скачайте локальные модели через Ollama:
   ```bash
   ollama pull llava
   ollama pull qwen2.5:3b
   ```

5. Запустите сервер:
   ```bash
   node --env-file=.env web-server.js
   ```

6. Откройте в браузере: `http://localhost:3000`
